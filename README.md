# Assay House shared pages

Pages shared by link (no printer). Served by GitHub Pages at
https://tazdejager-pixel.github.io/assay-house-share/

## temp/

Everything in `temp/` is disposable: one-off documents shared for a meeting, an interview or a
review. Each item lives in its own folder named `YYYY-MM-short-name/`. To clean up, delete the
folder (or the whole of `temp/`). Nothing outside `temp/` links into it.

Every page carries `noindex` so search engines do not list it.
